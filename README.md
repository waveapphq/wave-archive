# WAVE archive

This repo keeps old design files and pictures of WAVE, the Workflow Automation and Validation Engine. None of it is kept up to date. For the current product and design, see the code in [waveapphq/wave](https://github.com/waveapphq/wave) and the docs in [waveapphq/wave-docs](https://github.com/waveapphq/wave-docs).

There are three topics:

- **wireframes:** early sketches of the screens, drawn in the Frame0 app. `Frame0` holds the Frame0 files and `screens` the pictures made from them.
- **mockups:** designs of screens that were built.
- **screenshots:** pictures of the running product.

Files sit in folders by month, such as `mockups/2026-Aug/` or `wireframes/screens/2025-Dec/`.
